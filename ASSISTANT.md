# Optional Grok review assistant

The scanner continues capture/upload → local OCR → human review → confirmation → CSV. Grok is off by default and never runs in the OCR worker or queue. The review card offers warning explanation, photo advice, a follow-up question, and an explicit **Ask Grok to read this field** action. Only the last action sends a field image, after a confirmation prompt. AI values are shown separately. **Use suggestion** enters a value into the ordinary unconfirmed review save; the clerk must inspect evidence and select **All good**. Barcode decoding remains authoritative for Sample ID, so an AI Sample ID proposal cannot be applied from the assistant.

## Install and update on a Pi

Follow the [fresh install and model predownload instructions](README.md) first. The assistant adds only `httpx` to the Pi requirements and adds no local model or training weights. Install the updated `requirements.txt` in `.venv-ocr`. With the app stopped, back up `scanner.sqlite3` and `uploads/` before updating an existing Pi. This main branch clears uploaded photos and closes prior sessions on startup; export a CSV before stopping if those photos are needed. The assistant table is created automatically on first start. Keep one Uvicorn worker: multiple workers would start multiple OCR queues and split the in-memory assistant concurrency limit.

Set environment variables in a private service environment file or shell using [.env.example](.env.example) as a placeholder guide. Never commit secrets. Set a long random `SCANNER_ACCESS_PASSWORD` even if cloud assistance is disabled. Start or restart with `bash scripts/start_demo.sh`. The script binds to `127.0.0.1` by default. For access from a shared network, terminate trusted HTTPS in a reverse proxy and forward to `127.0.0.1:8000`. Set `SCANNER_ALLOWED_ORIGINS` to the exact external HTTPS origin. Webcam browsers require HTTPS or localhost. Do not expose Basic authentication over plain HTTP. The browser prompts for user `clerk` and the configured password. All routes, including status, photos, crops, review, export, cleanup, and assistance, require that credential. Mutations check `Origin` and cross-site fetch metadata. This is a shared clerk password, not per-person identity or an audit trail.

For example, a Caddy site with a trusted certificate can use `scanner.example.local { reverse_proxy 127.0.0.1:8000 }`; set `SCANNER_ALLOWED_ORIGINS=https://scanner.example.local`. If using Caddy's `tls internal`, install and trust its root certificate on every clerk device before logging in. Keep port 8000 bound to loopback and expose only the HTTPS site.

Set `ASSISTANT_ENABLED=true`, `XAI_API_KEY`, and optionally `ASSISTANT_IMAGE_ENABLED=true` after approving external image transmission. The key remains on the server. To rotate it, replace the private environment value, restart, and revoke the old key in the xAI console. To disable cloud calls, set `ASSISTANT_ENABLED=false` and restart. The [Responses API](https://docs.x.ai/developers/rest-api-reference/inference/responses) uses `https://api.x.ai/v1/responses`; `https://us.api.x.ai/v1/responses` is also allowed. The default model is `grok-4.7`, which xAI [lists for text and image input](https://docs.x.ai/developers/models/grok-4.7). Set `XAI_MODEL` only to an account-supported image-capable model. The server supplies no search, remote, or code tools. It sends only the selected crop, never a public URL or automatic upload.

## Limits, errors, and retention

`ASSISTANT_CONNECT_TIMEOUT`, `ASSISTANT_READ_TIMEOUT`, and `ASSISTANT_TOTAL_TIMEOUT` are seconds. `ASSISTANT_OUTPUT_TOKENS` limits output. `ASSISTANT_CONCURRENCY`, `ASSISTANT_PER_MINUTE` (per connecting device address), and `ASSISTANT_DAILY_REQUESTS` bound requests. Each reserved request counts against the daily limit, including failures and requests in flight. This is a request ceiling, **not** an exact dollar ceiling. Inspect token usage in the local `assistant_requests` table and actual billing in the xAI console; failed or in-flight requests can incur charges. [xAI model prices](https://docs.x.ai/developers/models) can change. Missing keys, no internet, DNS/TLS failures, bad credentials, exhausted credits, rate limits, timeouts, server errors, and malformed replies affect only cloud assistance. Local scanning, review, and export remain available offline.

The app does not store chat history or image payloads in assistant records. It stores short responses or proposals with operational metadata for at most seven days to suppress duplicates and safely apply suggestions. Session finish and startup upload cleanup clear response/proposal content; hourly maintenance prunes records older than seven days. The server sends `store:false`, which disables provider stateful response storage but does **not** mean zero provider retention. xAI's [security FAQ](https://docs.x.ai/developers/faq/security) describes default 30-day audit retention. Account-level Zero Data Retention is separate and must be verified in the xAI console or response header before claiming it. Local deletion does not delete provider-held data.

For rollback, stop the app, restore the prior source checkout and matching database/uploads backup, then restart with the previous environment. The added table can remain unused. Do not restore only the database without its matching uploads. Physical Pi camera/iPhone intake, model startup and memory, and a live xAI request with nonsensitive test labels remain hardware/provider checks; automated tests use a mock and make no paid calls.

## Evaluation procedure

Reserve unseen physical tubes and writers separately from development examples. Randomize review order and compare local OCR plus human review, local OCR plus text assistance, and local OCR plus opt-in Grok crop reading. Record exact field accuracy against independently transcribed ground truth, incorrect suggestions, incorrect suggestions accepted, abstention rate, correction time, assistant latency, token/image usage and billed cost, Pi memory and responsiveness during OCR, and offline/provider-failure behavior. OCR/Grok agreement is not ground truth.
